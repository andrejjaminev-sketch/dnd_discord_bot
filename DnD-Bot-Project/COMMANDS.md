\# 📜 Полный справочник команд D\&D Bot



\*\*Как использовать:\*\*  

\- Префикс команд: `!`  

\- Числовые ID пишутся без скобок  

\- Текст с пробелами можно оборачивать в двойные кавычки `"`, но не обязательно  

\- Пример: `!char\_name Grom the Steel` = `!char\_name "Grom the Steel"`



\---



\## 👤 Персонаж – просмотр и создание



\- `!char\_id <id>` — полная карточка персонажа по ID

\- `!char\_name <имя>` — карточка персонажа по имени

\- `!char\_user\_id <user\_id>` — список персонажей игрока по его ID

\- `!char\_username <логин>` — список персонажей игрока по его имени

&#x20; \*(Если персонажей несколько, выводится строка «Имя + ID» для каждого)\*

\- `!char\_create <имя>` — создать нового персонажа (раса Human по умолчанию)

\- `!char\_delete <id>` — удалить персонажа полностью



\## ✏️ Персонаж – изменение основных полей



\- `!char\_name\_change <id> <новое имя>` — изменить имя персонажа

\- `!char\_age\_change <id> <возраст>` — изменить возраст

\- `!char\_lvl\_change <id> <уровень>` — изменить уровень персонажа

\- `!char\_species\_change <id> <race\_id>` — сменить расу

\- `!char\_user\_id\_change <id> <новый user\_id>` — передать персонажа другому пользователю



\## 🛡️ Классы и ветки персонажа



\- `!char\_class\_add <id> <class\_id>` — добавить класс персонажу

\- `!char\_class\_remove <id> <class\_id>` — убрать класс у персонажа

\- `!char\_class\_lvl\_change <id> <class\_id> <уровень>` — изменить уровень класса

\- `!char\_class\_info <id> <class\_id>` — показать детальную информацию о классе у персонажа (ветки, очки, уровни)

\- `!char\_branch\_invest\_points <id> <branch\_id> <кол-во>` — вложить очки прокачки в ветку

\- `!char\_branch\_invested\_points\_set <id> <branch\_id> <кол-во>` — установить точное количество вложенных очков

\- `!char\_branch\_lvl\_set <id> <branch\_id> <уровень>` — принудительно установить уровень ветки

\- `!char\_branch\_reset <id> <branch\_id>` — сбросить ветку к начальному состоянию



\## ✨ Способности персонажа



\- `!char\_ability\_add <id> <ability\_id>` — добавить способность без траты очков

\- `!char\_ability\_buy <id> <ability\_id>` — купить способность за свободные очки

\- `!char\_ability\_remove <id> <ability\_id>` — забыть способность



\## 📊 Статы и 💧 Пулы персонажа



\- `!char\_stat\_add <id> <stat\_id>` — добавить персонажу новый стат

\- `!char\_stat\_remove <id> <stat\_id>` — убрать стат

\- `!char\_stat\_lvl\_change <id> <stat\_id> <значение>` — изменить значение стата

\- `!char\_pool\_add <id> <pool\_id>` — добавить персонажу новый пул

\- `!char\_pool\_remove <id> <pool\_id>` — убрать пул

\- `!char\_pool\_current\_value\_change <id> <pool\_id> <новое значение>` — изменить текущее значение пула (здоровье, мана и т.п.)

\- `!char\_pool\_base\_change <id> <pool\_id> <новое базовое>` — изменить базовое значение пула

\- `!char\_pool\_coefficient\_change <id> <pool\_id> <коэффициент>` — изменить коэффициент пула



\## 📝 Заметки персонажа



\- `!char\_notes\_add <id> <заголовок> <содержание>` — добавить заметку

\- `!char\_notes\_show\_all <id>` — показать все заметки (заголовок + ID)

\- `!char\_notes\_show\_one\_id <id> <note\_id>` — показать заметку по её ID

\- `!char\_notes\_show\_one\_title <id> <заголовок>` — показать заметку по заголовку

\- `!char\_notes\_remove <id> <note\_id>` — удалить заметку



\## 🎒 Инвентарь



\- `!inv\_show <char\_id>` — показать инвентарь персонажа (вес, предметы)

\- `!inv\_add <char\_id> <item\_id> \[количество]` — добавить предмет в инвентарь

\- `!inv\_set <char\_id> <item\_id> <количество>` — установить точное количество предмета (0 = удалить)

\- `!inv\_remove <char\_id> <item\_id>` — полностью удалить предмет из инвентаря



\## 🛡️ Экипировка



\- `!equip\_show <char\_id>` — показать надетые предметы по слотам

\- `!equip <char\_id> <item\_id> <slot\_id>` — надеть предмет в указанный слот (заменяет предыдущий)

\- `!unequip <char\_id> <slot\_id>` — снять предмет из слота

\## 📚 Справочники мира



\### 📖 Классы

\- `!class\_show\_all` — список всех классов (имя + ID)

\- `!class\_show\_id <id>` — подробная информация о классе (ветки, уровни, способности)

\- `!class\_show\_name <имя>` — информация о классе по названию

\- `!class\_create <имя> <описание>` — создать новый класс

\- `!class\_delete <id>` — удалить класс

\- `!class\_name\_change <id> <новое имя>` — переименовать класс

\- `!class\_description\_change <id> <новое описание>` — изменить описание класса

\- `!class\_show\_all\_branches <id>` — показать все ветки класса (название + ID)



\### 🌳 Ветки

\- `!branch\_info\_id <id>` — полная информация о ветке (уровни, требуемые очки, способности)

\- `!branch\_info\_name <имя>` — информация о ветке по названию

\- `!branch\_create <class\_id> <имя> <описание>` — создать новую ветку

\- `!branch\_delete <id>` — удалить ветку

\- `!branch\_name\_change <id> <новое имя>` — переименовать ветку

\- `!branch\_description\_change <id> <новое описание>` — изменить описание ветки

\- `!branch\_lvl\_create <branch\_id> <lvl> <требуемые\_очки> <ability\_id>` — создать уровень ветки с привязкой способности

\- `!branch\_lvl\_delete <lvl\_id>` — удалить уровень ветки



\### ✨ Способности

\- `!ability\_show\_all` — список всех способностей (имя + ID)

\- `!ability\_info\_id <id>` — информация о способности по ID (описание, стоимость)

\- `!ability\_info\_name <имя>` — информация о способности по названию

\- `!ability\_create <имя> <описание>` — создать новую способность

\- `!ability\_delete <id>` — удалить способность

\- `!ability\_change <id> <новое имя> <новое описание>` — изменить название и описание способности

\- `!ability\_cost\_change <id> <pool\_id> <стоимость>` — задать стоимость использования (расход пула)

\- `!ability\_cost\_remove <id>` — удалить все стоимости способности

\- `!ability\_set\_type <ability\_id> <type\_id>` — сменить тип способности (1=active, 2=passive)
